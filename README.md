Folders:

"/biogeography/" - Includes:
1-the results from the biogeographyc inference (*.png, speed.txt, speed.svg)
2-input files (*.csv)

"noclock3/" - Includes:
1- The input nexus file with morphological data partitioned by state number 
2- The consensus tree file

"state_part" - Includes:
1- The input nexus file with morphological data partitioned by state number, and implementing two relaxed clock models ("tk02" or "igr") and two sampling strategies ("div" or "ran")  
2- The consensus tree file under each case.
 

"source_part" - Includes:
1- The input nexus file with morphological data partitioned by state number and character origin, and implementing two relaxed clock models ("tk02" or "igr") and two sampling strategies ("div" or "ran")  
2- The consensus tree file under each case.

Note that due to size limitation, other output files are not uploaded:
- mcmc
- post burn-in tree files
- brparams
- *.p
